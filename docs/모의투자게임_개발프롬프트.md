# 공개수업용 교육 모의투자 게임 — Claude Code 개발 프롬프트

> 이 파일 전체를 Claude Code(홈페이지 저장소)에 붙여넣어 사용하세요.

---

기존에 만들어져 있는 내 홈페이지에 학생들이 스마트폰으로 접속해서 참여하는 **교육용 모의투자 게임**을 추가해줘.

## 0. 작업 시작 전 (코드 작성 금지 단계)

먼저 아래를 설명하고, 내 확인을 받은 뒤에 개발을 시작해라.

1. 현재 프로젝트의 기술 스택
2. 파일/폴더 구조와 기존 페이지 구조
3. 수정할 파일과 새로 만들 파일 목록
4. 기존 기능을 훼손하지 않기 위한 방법

기존 홈페이지의 기술 스택과 디자인은 최대한 유지하고, 전부 교체하지 마라.

## 1. 목적과 법적 원칙

이 서비스는 실제 금융상품을 거래하거나 투자금을 받는 서비스가 아니라, 학생들이 주식시장과 경제 원리를 게임으로 배우는 **교육용 가상 모의투자 콘텐츠**다.

- 모든 참가자는 시작 시 동일한 **가상 포인트 100,000,000P(1억 P)** 를 받는다. (관리자 화면에서 변경 가능한 설정값, 기본값 1억)
- P는 실제 돈이 아니다. 실제 현금 가치 0원, 출금·환전·현금화 불가.

**절대 구현하지 않는 것**
- 실제 돈 입금/출금, 포인트 현금화, 경품·상금 연동
- 실제 증권사 계좌 연결, 실제 주문 전송, 자동 실제 주문
- 투자금 모집, 유료 투자 추천
- 특정 종목 매수/매도 권유, 수익 보장 표현 ("이 종목을 사세요", "지금 사면 수익" 등)

**모든 화면 하단에 고정 표시할 문구**
> 본 서비스는 교육 및 게임 목적으로 제작된 가상 모의투자 콘텐츠입니다. 실제 금융투자 또는 증권거래가 아니며, 실제 금전적 가치가 없는 가상 포인트를 사용합니다.

종목 설명은 교육·정보 제공 목적으로만 쓴다. 좋은 표현: "게임 내 모의매매 결과입니다."

## 2. 참가 흐름

1. 학생이 QR코드로 접속 → 첫 화면 `SAFE INVEST — 우리 반 모의투자 챌린지`
2. 게임 안내 확인 후 [확인하고 참가하기]
   > 이 게임은 금융교육 및 수업 활동을 위한 가상 모의투자 게임입니다. 게임에서 사용하는 포인트는 실제 돈이 아니며 현금으로 교환할 수 없습니다. 게임 결과는 실제 투자수익을 의미하지 않습니다. 실제 투자 판단은 각자의 책임과 충분한 정보 확인이 필요합니다.
3. **닉네임만** 입력 (실명·전화번호·주소 등 수집 금지). 서버가 랜덤 참가 ID를 부여해 닉네임 중복을 방지한다.
4. 1억 P 지급 후 게임 시작

## 3. 핵심 기능

### 메인 화면 (모바일 우선)
- 상단: 닉네임, 보유 가상현금, 주식 평가금액, 총자산, 게임 수익률, 현재 순위
- 종목 검색 (삼성전자, SK하이닉스, 현대차, NAVER, 카카오 등)
- 종목 상세: 현재 게임 가격, 전일 대비 등락률, 가격 차트, 거래량, 기본정보

### 차트
- 반응형, 기간 선택(1일 / 1주 / 1개월 / 3개월), 가능하면 캔들차트
- **DEMO MODE**(샘플 데이터)로 API 없이 동작하게 먼저 만든다.

### 가상 매수 — 매수 이유 필수
- 종목, 수량 선택 → 예상 거래금액 표시
- **매수 이유 입력란 필수** (빈 값이면 매수 불가, 서버에서도 검증)
  - 입력 안내: "왜 이 종목을 선택했나요? 나만의 근거를 적어보세요."
  - 최소 글자수(예: 10자)와 최대 글자수(예: 200자) 제한
  - 거래 전 확인창 표시 (실수 방지)
- [모의 매수] 클릭 시 실제 주문이 아니라 **게임 DB에 가상 거래 기록만** 저장

### 가상 매도
- 보유한 가상 주식만 매도 가능, 매도 이유도 입력(필수 또는 선택은 관리자 설정)
- 매도 후: 가상현금 증가, 보유수량 감소, 거래기록 저장, 실현손익 계산

### 포트폴리오
- 가상현금, 종목별 보유수량·평가금액·수익률, 총자산, 게임 수익률
- 종목별 **내가 적은 매수 이유** 함께 표시

## 4. 랭킹과 수익률 비교 (핵심 재미 요소)

- 총자산 기준 실시간 순위를 **1위부터** 표시: `순위 / 닉네임(ID) / 총자산 / 수익률`
  ```
  🏆 우리 반 모의투자 랭킹
  1위 닉네임A  112,500,000P  +12.5%
  2위 닉네임B  108,600,000P  +8.6%
  3위 닉네임C  107,100,000P  +7.1%
  ```
- 참가자를 누르면 그 사람의 **포트폴리오와 종목별 수익률 비교** 화면을 보여준다. (나 vs 상대 비교)
- **매수 이유 공개 시점은 관리자 설정**으로 둔다.
  - `게임 종료 후 공개`(기본값 — 서로 따라 사는 것을 방지)
  - `실시간 공개`
- 랭킹 하단에 안내: "순위는 게임 내 총자산 기준이며 실제 투자 성과나 미래 수익을 의미하지 않습니다."
- 수업 화면에 띄울 **실시간 전체 순위 전용 페이지**를 별도로 만든다. (큰 글씨, 자동 갱신)

## 5. 이벤트 시스템과 교사용 관리자 페이지

학생에게 절대 노출되지 않도록 분리하고, 관리자 인증(비밀번호/토큰)을 둔다.

- 이벤트 생성 / 시작 / 종료, 종료 시간 설정
- 시작 가상자금 설정(기본 1억 P), 종목 목록 설정
- 매수 이유 공개 방식 설정
- 참가자 수·목록, 현재 1위, 전체 순위, 평균 수익률
- 거래 횟수, 종목별 거래량, 이벤트 진행시간
- 전체 거래 기록(매수 이유 포함) 조회
- 게임 초기화

## 6. 게임 요소와 교육 콘텐츠

- 오늘의 미션 예: "1억 P로 포트폴리오를 구성해보세요", "서로 다른 3개 종목에 나눠 담아보세요", "한 종목에 모두 넣었을 때의 위험을 확인해보세요"
- 게임 중간에 짧은 금융교육 카드(주식이란? / 분산이란? / 위험과 수익) — 특정 종목 추천처럼 쓰지 않는다.
- 종료 후 **나의 투자 리포트**: 총자산, 수익률, 가장 많이 거래한 종목, 분산 비율, 거래 횟수, 최대 평가손익, 내가 적은 매수 이유 모아보기
- 교육 설명은 단정하지 말 것. 예: "이번 게임에서는 한 종목에 자산이 집중되었습니다. 실제 투자에서도 자산을 나누는 방식이 위험 관리에 활용될 수 있습니다." 특정 전략을 정답으로 제시하지 않는다.

## 7. 보안 / 부정행위 방지 / 개인정보

- 보유 현금, 보유 주식, 거래 가격, 총자산, 수익률, 순위는 **전부 서버에서 계산·검증**한다. 브라우저 값은 신뢰하지 않는다.
- 거래 가격은 클라이언트가 보낸 값을 쓰지 말고 서버가 가진 게임 가격으로 체결한다.
- 수량·이유 텍스트 입력 검증, XSS 방어(매수 이유는 반드시 이스케이프), 요청 빈도 제한
- 개인정보는 닉네임 + 랜덤 참가 ID만 수집한다.
- 시장 데이터 API 키는 프론트엔드에 노출하지 말고 서버 환경변수로 관리한다.

## 8. 데이터 구조 (참고)

- users: id, nickname, participant_code, created_at
- events: id, name, start_at, end_at, initial_balance, status, reason_reveal_mode
- holdings: user_id, event_id, ticker, quantity, average_price
- transactions: id, user_id, event_id, ticker, type, quantity, price, **reason**, created_at
- leaderboard: event_id, user_id, total_assets, return_rate, rank

## 9. 시장 데이터

- `DEMO MODE`: 미리 준비한 샘플 데이터 (개발 초기 기본값)
- `MARKET DATA MODE`: 이용약관·라이선스를 허용한 API만 사용. 키는 서버 환경변수.
- 두 모드를 설정으로 전환 가능하게 구조를 만든다.

## 10. 모바일 UI 조건

- 320px 이상 정상 동작, 큰 터치 버튼, 읽기 쉬운 글자, 가로 스크롤 최소화
- 차트도 모바일에 맞게 표시, 매수/매도 버튼 분리·색상 구분, 거래 전 확인창

## 11. 개발 순서 (한 단계씩, 각 단계 테스트 후 다음으로)

1. 모의투자 게임 화면 골격 + 면책 문구
2. 종목 목록 및 샘플 가격(DEMO MODE)
3. 가상 매수/매도 (매수 이유 필수 검증 포함)
4. 포트폴리오
5. 수익률 계산 (서버)
6. 실시간 랭킹 + 수익률 비교 화면
7. 교사용 관리자 페이지 + 수업용 전체 순위 페이지
8. 시장 데이터 API 연결(선택)
9. 공개수업용 UI/애니메이션 개선, 종료 후 투자 리포트

## 12. 최종 흐름

QR 스캔 → 홈페이지 접속 → 안내 확인 → 닉네임 입력 → 1억 P 지급 → 종목 선택 → **매수 이유 작성** → 가상 매수/매도 → 총자산·수익률 계산 → 실시간 순위 반영 → 수업 종료 → 매수 이유 공개 및 최종 투자 리포트

먼저 **0번 항목(현재 프로젝트 분석과 수정 계획)** 부터 보고해라.
