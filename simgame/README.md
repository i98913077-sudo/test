# SAFE INVEST — 공개수업용 교육 모의투자 게임

너굴이들이 휴대폰으로 접속해 **가상 포인트(기본 1억 P)** 로 모의 매매를 해보는 교육용 게임입니다.
실제 돈·실제 주문·투자 권유·수익 보장은 **없습니다.** (모든 거래는 게임 DB의 기록일 뿐입니다.)

## 실행

```bash
cd simgame
ADMIN_PASSWORD=원하는비밀번호 npm start      # 기본 http://localhost:3000
```

- Node.js 22.5 이상 필요 (내장 `node:sqlite` 사용 → **npm 설치 불필요, 외부 패키지 0개**)
- `ADMIN_PASSWORD`를 안 주면 서버 콘솔에 임시 비밀번호가 출력됩니다. (코드에 기본 비밀번호 없음)
- 환경변수: `PORT`, `ADMIN_PASSWORD`, `DB_PATH`(기본 `data/game.db`), `FRAME_ANCESTORS`(홈페이지에 iframe으로 넣을 때 허용할 출처, 예: `https://내홈페이지.com`), `DEMO_VOLATILITY`(샘플 가격 변동폭 배율)

| 주소 | 용도 |
|---|---|
| `/` | 너굴이 참가·게임 화면 (모바일 우선, 320px 이상) |
| `/ranking` | 수업 화면용 실시간 전체 순위 (3초마다 갱신) |
| `/admin` | 너굴 관리자 |

## 수업 진행 순서
1. `/admin` 로그인 → **새 이벤트 만들기** (시작 자금 기본 1억 P, 진행 시간, 종목, 매수 이유 공개 시점 설정)
2. 너굴이 접속 주소를 QR코드로 만들어 띄움 (QR 생성기는 포함되어 있지 않습니다 — 무료 QR 사이트 이용)
3. 너굴이이 닉네임만 입력해 참가 → 너굴이 **게임 시작**
4. `/ranking` 을 큰 화면에 띄움
5. 시간이 끝나면 자동 종료(또는 **게임 종료**) → 매수 이유 공개, 너굴이별 투자 리포트 확인
6. 거래 기록은 관리자에서 CSV로 내려받아 토론 자료로 사용 가능

## 구현된 기능
- 참가: 닉네임 + 자동 랜덤 참가 코드(동명이인 구분). 안내문 동의 후 참가. 개인정보 수집 없음
- 종목 검색, 현재 게임 가격·등락률·거래량, **캔들차트**(1일/1주/1개월/3개월, 터치로 값 확인)
- 가상 매수/매도: 수량 선택, **매수 이유 필수(10~200자, 서버 검증)**, 거래 전 확인창
- 포트폴리오(종목별 수익률·평가손익·내가 적은 이유), 거래 기록
- **랭킹(1위부터 닉네임·총자산·수익률)** + 참가자 간 **수익률/포트폴리오 비교**
- 매수 이유 공개 시점: 게임 종료 후(기본) / 실시간 — 종료 전에는 타인의 이유·보유종목이 API에서도 내려가지 않음
- 종료 후 **투자 리포트**: 총자산·수익률·거래 횟수·가장 많이 거래한 종목·분산 비율·최고/최저 총자산·평가손익·교육 해설
- 금융교육 카드, 오늘의 미션
- 너굴(운영자)용: 이벤트 생성/시작/종료/초기화, 설정, 참가자·순위·거래량·평균 수익률, 거래 기록(이유 포함), CSV

## 법적·안전 설계
- 모든 화면에 "교육용 가상 모의투자" 배너와 안내문 표시, 참가 전 동의 필수
- 구현하지 않은 것: 입출금, 현금화, 증권사 연동, 실제 주문, 투자금 모집, 종목 추천, 수익 보장
- 종목 설명·리포트 해설은 관찰 중심 문구이며 특정 전략을 정답으로 제시하지 않음 (테스트로 금지 표현 검증)
- 부정행위 방지: 현금·보유·체결가·총자산·수익률·순위는 **전부 서버가 계산**. 클라이언트가 보낸 가격/현금 값은 무시
- 보안: 관리자 인증, 토큰은 해시 저장, 요청 크기·빈도 제한, CSP(`script-src 'self'`), innerHTML 미사용(XSS 방지), CSV 수식 주입 방지, 정적 파일 경로 이탈 차단
- 샘플 가격은 서버가 DB에 저장한 **비밀 시드**로 생성합니다. 저장소가 공개여도 미래 가격을 계산할 수 없습니다

## 시장 데이터
- 현재 **DEMO MODE(샘플 데이터)** 만 구현되어 있습니다. 실제 시세가 아니며 교육 효과를 위해 변동폭을 실제보다 크게 잡았습니다. 샘플 시장은 24시간 움직입니다.
- 실제 시세(MARKET DATA MODE)는 미구현입니다. 연결하려면 `lib/market.js`의 `priceAt / candles / prevClose / todayVolume` 인터페이스를 구현하는 어댑터를 만들고, 데이터 제공처의 이용약관·라이선스를 확인한 뒤 API 키를 **서버 환경변수**로만 관리하세요.

## 알아둘 점
- 너굴이이 브라우저 저장소를 지우면 참가 정보(토큰)가 사라져 같은 계정으로 돌아올 수 없습니다. (개인정보를 받지 않는 설계의 trade-off)
- 이벤트는 한 번에 하나만 진행됩니다. 서버는 단일 프로세스를 가정합니다(수십 명 규모의 교실 사용에 맞춤).
